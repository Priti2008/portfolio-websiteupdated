# Portfolio Website

## Project Description

This is a responsive personal portfolio website created using HTML and CSS. The website showcases my skills, projects, and contact information.

## Technologies Used

* HTML5
* CSS3

## Features

* Responsive Design
* Home Section
* About Section
* Skills Section
* Projects Section
* Contact Section
* Hover Effects

## File Structure

* index.html
* style.css
* screenshots/

## Setup Instructions

1. Download the project files.
2. Open index.html in any web browser.
3. Explore the portfolio website.
